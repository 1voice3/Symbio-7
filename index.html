How to use it

Install from GitHub on iPhone

  1. Extract the ZIP and upload index.html, manual-index.txt, and manual.pdf into the same GitHub repository folder.
  2. Enable GitHub Pages for the repository (Settings → Pages) and open its published URL in Safari.
  3. Use Safari’s Share button → Add to Home Screen for an app-like icon and full-screen shortcut.
  4. Keep all three files together; the app fetches manual-index.txt for full-manual search and opens manual.pdf for page citations.

The app is static and requires no account, API key, backend, or build step. Search works on the published HTTPS site. If the manual is hosted elsewhere, set its direct PDF URL in “Manual link settings.”
